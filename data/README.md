# Sample data

- `sample_goodreads.csv`: a sample reader's library in Goodreads export format. Ratings, dates and page counts are **made-up placeholders**. Replace it with your own export (Goodreads → My Books → Import and export → Export Library).
- `sample_clippings.txt`: a Kindle `My Clippings.txt` in the real format. The highlight text is **paraphrased placeholder text**, not quotes from the books. It deliberately includes a duplicate and a bookmark so the parser has something to skip.
- `sample_catalog.json`: a small offline "Open Library" used by demo mode, tests and evals, so everything runs without network access.
