# Sample data

- `sample_goodreads.csv`: built from the public favourites and currently-reading books on goodreads.com/user/show/57146668. Ratings, dates and page counts are **made-up placeholders**. Replace this file with your real export (Goodreads → My Books → Import and export → Export Library).
- `sample_clippings.txt`: a Kindle `My Clippings.txt` in the real format. The highlight text is **paraphrased placeholder text**, not quotes from the books. It deliberately includes a duplicate and a bookmark so the parser has something to skip.
- `sample_catalog.json`: a small offline "Open Library" used by mock mode, tests and evals, so everything runs without network access.
